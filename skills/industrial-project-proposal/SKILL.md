# Industrial Project Proposal

## 典型请求
立项论证、技术选型、产线改造、设备/相机/镜头/光源/PLC/运动卡比较、软件系统设计、报价前技术范围确认。

## 工作流
1. 明确谁是读者（技术、采购、管理层、现场验收），列现状痛点、生产节拍、精度、良率、产能、安全、成本、工期等要求；未知项单列。
2. 写范围及边界：交付内容、不包含内容、现场施工与客户配合、已有接口、假设与依赖。
3. 描述需求 → 系统架构 → 关键技术路线 → 核心设备选型；至少给推荐/备选与取舍。
4. 对视觉设备必须检验 FOV、分辨率、WD、安装干涉、光源、定位误差预算、样本覆盖与标定维护。
5. 对运动/电气定义轴系、抓取机构、IO 接口、联锁、产线握手、通信异常、停机和人工接管。
6. 输出实施阶段（评估、POC、详细设计、开发、FAT、SAT、交付）；每阶段有里程碑、责任、入口条件和验收证据。
7. 风险登记：触发条件/影响/概率/预防措施/应对人；关键数据不得无来源承诺。
8. 报价/周期为估算时列明口径、排除项和置信度，不制造“已确定”。

## 建议章节
执行摘要、背景与目标、现场输入、需求/边界、系统总体架构、关键技术、方案对比、关键参数与预算、实施排期、风险、安全与验收、附件。
从仓库根目录的 templates/proposal.md 复制模板，如无法访问则遵循同样标题。

## 输出质量
图表应包含单位、版本、来源。任何精度/节拍/ROI/成本必须是有数据可追溯的事实、明确估算或待验证假设之一。
