# Qt Industrial UI

## 适用
工位监控、相机画布、ROI 编辑、模板管理、标定进度、运动控制、报警诊断、历史报表或流程可视化；对现有 Qt 5.12 项目优先 Qt Widgets 可用组件。

## 页面设计步骤
1. 明确使用角色：操作员、调试员、工程师、管理员；操作权限与危险动作隔离。
2. 绘制信息层级：主任务画面优先，状态/告警始终可见，次级设置按 Tab/折叠分组；画布、属性和步骤区按真实使用频率分配空间。
3. 制作页面状态矩阵：未连接、就绪、运行、成功、失败、警告、禁用、无结果。颜色须配合图标/文字，不能仅靠红绿。
4. 流程高亮区分“正在执行”“已完成 OK”“检测 NG”“设备故障”“跳过”，不同语义不能共用状态。
5. 标定 UI 分离进度展示和算法结果：点位完成数、当前点、坐标/角度、异常、重试；不得把未采集数据填为成功。
6. 界面控件操作发出命令，业务状态以设备/执行器回报为准；错误弹窗不能抢占急停与现场安全流程。

## 实现约束
- UI 线程不得等待 HALCON、相机、PLC、运动轴返回。
- 组件尺寸采用 layout 管理，检查 125%/150% DPI 和最小窗口宽度。
- 单位明确（px/mm/deg/ms）；角度、坐标系、精度、置信度显示各自来源。
- 资源管理包含路径有效性、文件版本、激活状态、缺失时降级或阻断策略。
- 提交截图时以实机数据与合成示例区分，避免用虚构效果代替通过测试。

## 交付
页面线框/布局树、字段字典、状态转换表、危险操作确认清单、UI 自动/手工验收用例。
