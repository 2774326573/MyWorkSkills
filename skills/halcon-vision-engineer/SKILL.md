# HALCON Vision Engineer

## 输入
图像与拍摄条件、相机/镜头/光源、工作距离、像素/物理标定、样本量、目标外观变化、定位或测量容差、HALCON 版本与许可证。
缺失时列出测试假设，不虚构现场参数。

## 算法流程
1. 数据分桶：正常、边缘、难例、缺陷、不同颜色/材质/姿态/光照；训练/调参与最终测试样本隔离。
2. 确认问题类型：分类、存在性检测、定位、角度估计、尺寸测量或多模板多目标匹配；每项选择对应指标。
3. 预处理评估曝光、光源、反光与 ROI；先建立可解释的基线算法，再增加复杂度。
4. 使用 HALCON 运算符前核对当前版本函数签名、输出元组和异常处理；代码不依赖 dev_* 交互才能用于运行时。
5. 多模板匹配：分别记录 model id、Row/Column/Angle/Score、匹配区域和跨模板去重策略；不能仅凭高分强制合并不同目标。
6. 坐标体系：区分像素 Row/Column、相机坐标、机械 XY、抓取工具 TCP 和旋转中心；列出变换顺序和采样时的轴位置，角度符号与单位需验证。
7. 标定：记录原始观测、有效点、残差、重投影/重复定位误差及使用边界；标定文件须关联相机/镜头/安装位与版本。

## 结果契约
每个目标输出 target_id、template_id、pixel_pose、world_pose（仅在标定有效时）、score、valid、reason、timestamp、cycle_id。检测 NG 与图像/标定错误 NoResult 分开；不能将未拍到的区域判为无料。

## 验收指标
按照业务定义重复定位误差、漏检率、误检率、单张耗时、P95/P99 时延和工况覆盖；公式、样本数、单位和统计口径必须注明。

## 交付
HDevelop/HDevEngine 入口约定、参数表、ROI/标定资源关联、测试 CSV 字段、难例分析和发布回退说明。不得宣称样本外精度已经验证。
