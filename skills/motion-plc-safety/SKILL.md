# Motion / PLC Safety

## 核心原则
本 Skill 不是功能安全认证、不能代替安全 PLC/继电器、硬接线急停、护罩和风险评估。危险动作上线必须由有资质人员按适用标准与实机条件审核。

## 先建立设备合同
记录轴数/行程、正反限位、原点、抱闸、使能、输入输出电平与电气隔离、24V/5V 额定能力、现场总线、PLC 地址、运动卡型号、扫描周期和故障复位权限。未知不得凭常见做法假定兼容。

## 时序与状态
1. 画状态机 Idle → Ready → Busy → Done / Fault → Reset。准备、开始、完成确认、超时、复位必须逐项定义。
2. 每个命令明确边沿/电平语义、序列号或握手清零条件、执行超时和重发幂等性；禁止旧完成位被下一周期误消费。
3. 运动前确认安全链、区域占用、平台/夹爪间干涉、Z 高度、安全位置、轴使能和回原点条件。
4. 报警等级分提示、可恢复错误、强制停机；通信掉线、反馈不可信、失步、跟随误差均进入明确定义的安全状态。
5. 停止/急停后需要重新评估位姿有效性与持料状态，禁止“简单继续上次步骤”。

## 集成测试矩阵
上电 IO 高态；断线/重连；线圈残留；超时；完成信号抖动；重复触发；机械限位；传感器不一致；失电恢复；急停与安全门；多工位资源锁冲突；单爪失败与部分成功。
测试应在安全仿真/断开驱动条件先验证；真实设备逐级授权上机。

## 交付
IO/寄存器表、时序图、状态机、互锁表、报警码、FAT/SAT 用例与恢复作业指导书；现场实测和仅模拟结果必须分别标识。
