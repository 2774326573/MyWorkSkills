# 统一交付质量标准

## 数据与证据

| 结论类别 | 写法 | 示例 |
| --- | --- | --- |
| 实测事实 | 标注来源、时间、版本、样本数 | P95=xx ms（测试 CSV、N=xxx） |
| 估算 | 假设、计算依据、误差范围 | 按 3 次拍照估算节拍，待现场确认 |
| 计划目标 | 表示尚未达到 | 定位重复性目标 ≤0.05 mm |
| 未知 | 待确认，不自行补值 | 下相机工作距离：待结构图核验 |

不能将演示值、算法打分、像素量换算或单一良品试验写为正式精度/良率指标。

## 技术方案验收

- 范围清楚，含非目标和外部依赖。
- 设备和通讯条件可追踪（型号、WD、FOV、IO、电平、轴数、接口）。
- 给出系统图、状态机或时序图、至少一种备选方案。
- 风险与回退、FAT/SAT 判据明确。
- 成本和工期有口径且分清估算与承诺。

## 软件审查验收

- 变更与仓库版本对应，关键缺陷带复现条件。
- 构建/测试结果附实际命令与 PASS/FAIL/BLOCKED 状态。
- 线程退出、设备断线、异常停机、重新上电、结果串扰有覆盖。
- 未运行测试不能标为通过。

## 报告验收

- 封面、版本、日期、设备配置、测试范围与测试人员。
- 样本量、公式、数据来源与附件链接核对一致。
- 问题清单与最终放行意见有责任人。
- 正式签署与占位符区分。

## 宣传交付验收

- 数据经审批且可证明；未通过测试的数据只能标计划目标。
- 每个镜头分清实拍/产品录屏/动画/AI 合成。
- 商标、员工/客户肖像、音乐和第三方媒体核实授权。
- 设备危险动作展示不得暗示绕过安全保护。
- 技术卖点可理解、用词准确、字幕和音频可读可听。
