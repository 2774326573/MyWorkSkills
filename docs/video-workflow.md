# 工业宣传视频完整制作流程

## 交付物
1. 受众画像、核心卖点与证据表。
2. 脚本：时间码、画面、旁白、字幕、图形提示。
3. 分镜 CSV：参照 templates/storyboard.csv。
4. 素材目录：footage/、screen-recordings/、logo/、music/、voice/、render/（不将素材自动提交公开 Git 仓库）。
5. 粗剪预览与正式成片 MP4（实际渲染取决于素材与工具可用性）。
6. 成片 QA 检查表及授权台账。

## 针对工业视觉设备的录制建议
- 远景：整机轮廓、生产工位和安全装置。
- 中景：取放、运动平台、相机与光源协同。
- 特写：识别区域、OK/NG 可视化、报警界面、HMI 实际界面录屏。
- 叠加：坐标示意、流程高亮、设备联机时序、经证实的参数。
- 避免虚假的“AI 识别 100%”“零误差”“全面无人化”承诺。

## Remotion 可选实现
Remotion 官方 Skills：https://www.remotion.dev/docs/ai/skills

命令（需安装 Node.js，且目标环境可访问 npm）：

    npx skills add remotion-dev/skills

视频工程由 Remotion 初始化后，再基于已确认分镜与合规素材建立 Composition；按照官方当前文档选择预览和渲染命令。不要在未执行渲染或未核查文件时声称生成了 MP4。

## 16:9 60 秒示例结构
0–05s 痛点与应用场景；05–12s 整机亮相；12–35s 视觉定位→设备动作→质量反馈；35–48s 数据与运维能力；48–56s 产品价值；56–60s 品牌/联络方式。

实际片长和镜头按需求调整；不能用演示动画冒充工业现场。
