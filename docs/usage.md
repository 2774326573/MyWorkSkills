# 使用说明 · Skills 工作流

## 如何向 Agent 下达任务

建议把事实与任务放在同一次请求中，示例：

- 使用 engineering-constraints 和 industrial-project-proposal：为新设备出完整技术方案。现场参数未知处必须标待验证，提供两套方案与风险。
- 使用 industrial-code-review：按 P0/P1/P2 审查当前 C++ 变更，列出文件、触发路径、可复现步骤和最小修复。
- 使用 halcon-vision-engineer：分析多模板多目标定位，输出 HALCON 算子路径、坐标体系、去重规则与测试指标。
- 使用 industrial-test-report：基于日志、测试 CSV 与版本信息生成可审计报告，禁止虚构 PASS。
- 使用 industrial-presentation：面向管理层把技术方案改成 12 页汇报，标注需实拍的素材和数据来源。
- 使用 industrial-promo-video：为工业视觉设备策划 60 秒客户宣传片，附分镜 CSV 和实拍/动画标记。

## 标准闭环

需求、事实与边界 → 选用 Skill → 方案/代码/文档草稿 → 技术验证 → 安全与知识产权审查 → 交付。

## 工具能力边界

- Skill 是 Agent 的任务指令和规范，不等于程序、Qt 插件、HALCON 包或视频渲染引擎。
- 写了 PPT Skill 不保证 Agent 可以导出 PPTX；需要目标环境具备演示文稿工具。
- 写了视频 Skill 不保证可直接输出 MP4；正式成片需要视频素材、运行时、编解码器与渲染环境。
- OpenCode/Codex/Claude 客户端可能依版本有不同发现机制；安装后进行最小任务测试。
- 本仓库不与其他项目自动共享工作区和隐私数据。

## 推荐任务输入结构

**项目**：名字、仓库与分支、软件/硬件版本、当前进展

**目标**：最终需要什么文件或功能

**约束**：兼容性、安全、成本、时间、禁止修改范围

**资料**：图纸、代码路径、测量数据、照片/视频、日志

**验收**：预期数字、人工确认方式、现场/模拟范围
